## 2. Verified Security Controls Across All 5 Audit Domains

1. **Authentication, Sessions, Cookies & CSRF**:
   - `Settings` ([config.py](../../backend/app/core/config.py#L164-L226)) fails closed in `ENVIRONMENT=production` on `PAYMENT_SANDBOX_MODE=true`, `COOKIE_SECURE=false`, empty/wildcard/non-HTTPS `ALLOWED_ORIGINS`, SQLite `DATABASE_URL`, or weak/reused/placeholder HMAC secrets (`< 32` chars).
   - Argon2id (`t=3, m=65536, p=1`) password hashing with dummy constant-time hash checks on unknown emails; `HttpOnly`, `SameSite=Lax` cookies (`ecom_session`, `ecom_guest_cart`, `ecom_guest_orders` with `path=/api/v1` and 5-order cap); zero auth/CSRF/guest tokens persisted in `localStorage` or `sessionStorage` (`localStorage` used strictly for `"atelier-theme"`).
   - Fail-closed session/user validation (`401 AUTH_SESSION_EXPIRED` / `403 AUTH_ACCOUNT_DISABLED` + `clear_auth_cookies=True`), global `Origin`/`Referer`/`Sec-Fetch-Site` checks, and HMAC-verified `X-CSRF-Token` enforcement on state-changing routes; `sanitizeReturnTo` prevents open redirects across nested decoding passes.

2. **RBAC (`customer` / `staff` / `admin`) & Admin Console (`FE-003` + `BE-004`)**:
   - Backend endpoints enforce live `users.is_active` and `users.role` checks (`require_roles`, `require_roles_with_csrf`), restricting `POST /admin/orders/{order_number}/refund`, `GET /admin/users`, `PATCH /admin/users/{id}/role`, `PATCH /admin/users/{id}/status`, and `GET /admin/audit-logs` strictly to `admin`.
   - Frontend [admin-shell.tsx](../../frontend/src/components/admin/admin-shell.tsx) and [admin-primitives.tsx](../../frontend/src/components/admin/admin-primitives.tsx) (`AdminRoleGuard`) block component mounting and issue zero `/api/v1/admin/*` API requests for unauthorized roles; `"Issue Refund"` renders exclusively for `admin`; [admin-users-view.tsx](../../frontend/src/components/admin/admin-users-view.tsx) + [admin/service.py](../../backend/app/modules/admin/service.py) prevent self-demotion, self-deactivation, and removing the last active administrator (`ORDER BY User.id ASC FOR UPDATE`) while atomically revoking active sessions and omitting `password_hash`; [audit.py](../../backend/app/core/audit.py) scrubs secret keys to `"[REDACTED]"`.

3. **Checkout, Server Totals, Inventory Locks & Sandbox Payments (`FE-002` + `BE-003`)**:
   - [checkout-view.tsx](../../frontend/src/components/storefront/checkout-view.tsx) and [orders/schemas.py](../../backend/app/modules/orders/schemas.py) (`extra="forbid"`) prevent client-supplied pricing/discount/shipping/tax/total overrides.
   - Checkout scopes `Idempotency-Key` with SHA-256 + `pg_advisory_xact_lock` + canonical payload fingerprint comparison (`409 IDEMPOTENCY_KEY_CONFLICT`) and acquires locks in canonical deadlock-free hierarchy (`PaymentIntent id ASC -> Order -> InventoryReservation id ASC -> InventoryStock variant_id ASC`) with `_INT32_MAX` overflow checks.
   - [payments/router.py](../../backend/app/modules/payments/router.py) bounds webhook payloads (`<= 65_536` bytes) before signature validation; [payments/service.py](../../backend/app/modules/payments/service.py) enforces provider match, 300s replay window, constant-time HMAC-SHA256 verification, `ON CONFLICT DO NOTHING` event deduplication, and order amount/currency parity.
   - Repo-wide scan verified **zero** payment card PAN, CVV, or expiry inputs or schema columns anywhere in `frontend/src` or `backend/app`.

4. **XSS, Media Sanitization, CSP & Headers**:
   - Repo-wide search across `frontend/src/**` verified zero `dangerouslySetInnerHTML`, `eval`, `new Function`, `innerHTML`, `outerHTML`, `document.write`, `"use server"`, or `target="_blank"` sinks.
   - `sanitizeMediaUrl` constrains product images strictly to credential-free `https://` URLs or non-traversing `/assets/...` paths; [next.config.mjs](../../frontend/next.config.mjs) sets `poweredByHeader: false`, `X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`, `Permissions-Policy`, CSP (`object-src 'none'`, `frame-ancestors 'none'`, `base-uri 'self'`, `form-action 'self'`), and `/admin/:path*` `Referrer-Policy: no-referrer` + `Cache-Control: no-store`.
   - Backend pre-query slug/order/intent validators and escaped `ILIKE` filters prevent NUL-byte errors and wildcard injection.

5. **Test Runners, CLI, Dependencies, Docker & CI (`OPS-002` + `QA-E2E-001`)**:
   - Both [run_disposable_pg_pytest.py](../../backend/tests/run_disposable_pg_pytest.py) and [run_e2e_stack.py](../../frontend/e2e/run_e2e_stack.py) isolate disposable databases inside `%TEMP%`, explicitly reject port `5432` and `E:\databasesql\data`, strip ambient `PG*` overrides, scrub secrets (`[REDACTED]`) from preserved logs, and verify full child PID cleanup.
   - [compose.yaml](../../compose.yaml) binds DB port strictly to `127.0.0.1:5432:5432` with fail-fast `${VAR:?...}` secrets; Dockerfiles drop privileges to `appuser` / `nextjs` (`UID 10001`); [.github/workflows/ci.yml](../../.github/workflows/ci.yml) sets `permissions: contents: read` and masks ephemeral E2E test credentials.
