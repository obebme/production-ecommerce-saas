## Verified Static & Component Controls Summary

- **Session, Cookies & CSRF**: Zero auth, session, CSRF, or guest tokens stored in `localStorage` or `sessionStorage` (`localStorage` is restricted to `atelier-theme` `"light" | "dark"` UI preference). All API requests enforce `credentials: "include"`, keep `memoryCsrfToken` in memory only, attach `X-CSRF-Token` on mutating requests (`POST`, `PATCH`, `PUT`, `DELETE`) excluding `login`/`register`, execute at most one `GET /auth/me` refresh retry on `403 CSRF_INVALID`, and fail closed on `401 AUTH_SESSION_EXPIRED` / `403 AUTH_ACCOUNT_DISABLED`.
- **XSS, Media & Redirect Defense**: Zero `dangerouslySetInnerHTML`, `eval`, `new Function`, `innerHTML`, `outerHTML`, or `document.write` sinks in `frontend/src`. Strict allowlisting in `sanitizeMediaUrl` (`https://` without credentials or `/assets/...`) and `sanitizeReturnTo` (single-leading-`/` same-origin relative path) blocks scheme, backslash, control-char, and multi-pass percent-encoding bypasses.
- **Client RBAC Entry Gating & Price Integrity**: `AdminShell`, `AdminRoleGuard`, `StorefrontHeader`, and `AccountView` prevent admin UI mounting, navigation disclosure, and `/api/v1/admin/*` API requests for anonymous and `customer` users (as well as `/admin/users` and `/admin/audit-logs` for `staff`). Cart/product mutations submit only `{ variant_id, quantity }` / `{ quantity }` with server-authoritative pricing and stock notices.
