# Ui-Ux playbook

- Deliver user journeys, information architecture, tokens, component inventory, responsive breakpoints and form/error/empty/loading states.
- Keep specs in docs/design; avoid generating pixel-heavy assets or duplicate code unless explicitly requested.
- Address accessibility, checkout friction, admin tables and mobile UX.
- Supply a concise handoff for the frontend owner.

Use this skill only for tasks within its domain. Follow project `AGENTS.md` and task ownership; report evidence, not claims.
